Crossfade

Full-coverage prototype

Every non-Won't story in docs/backlog.md, drawn as static screens. Nothing works: no data, no saving, no logins. Each screen ends with a note naming the stories it serves and the gaps found drawing it.

MVP slice — the six-shot test

  1. Create a link: sender pastes a 25-track Apple Music link and the passcode.
  2. Building → Link ready: Matched 23 of 25, two misses named, Copy link.
  3. Link goes to a friend by text. Happens in Messages — no Crossfade screen.
  4. Recipient view: opens with no login, sees the same report.
  5. Taps Play in Spotify, audio plays. Happens in Spotify — can't be prototyped here.
  6. Library unchanged. Happens in Spotify.

Shots 3, 5 and 6 leave Crossfade. The slice is end-to-end only if the Spotify playlist really exists on Crossfade's account (PRD K3).
